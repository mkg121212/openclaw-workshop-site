INSTALL GUIDE

OpenClaw 安装指南

完全新手向：环境 → 安装 → 模型 → 聊天软件。

开始安装 直达 OpenClaw

SETUP

环境安装

macOS 环境

  • Homebrew
  • Node.js LTS（含 npm）
  • Git

安装命令

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install node git

测试命令

node -v
npm -v
git --version

Windows 环境

  • Node.js LTS（Windows x64 .msi）
  • Git for Windows（64-bit 安装包）
  • 推荐使用 PowerShell 或 Windows Terminal
下载 Node.js LTS 下载 Git for Windows

提示：下载页里选 LTS（长期支持版），并选择 Windows x64 安装包。

INSTALL

OpenClaw 安装

官方脚本一键安装 + npm 安装，两种方式任选其一。

一键安装（官方脚本）

macOS / Linux / WSL2：

curl -fsSL https://openclaw.ai/install.sh | bash

Windows（PowerShell）：

iwr -useb https://openclaw.ai/install.ps1 | iex

npm 安装（手动）

npm install -g openclaw@latest
openclaw onboard --install-daemon

安装完成验证

openclaw doctor
openclaw status
openclaw dashboard

MODELS

模型配置

本地模型用 Ollama，云端模型按 provider/model 填写。

Ollama 本地模型

安装 Ollama 后执行：

ollama pull qwen2.5:7b
ollama serve

OpenClaw 配置示例：

# primary: "ollama/qwen2.5:7b"
下载 Ollama Ollama 模型库

云端模型（通用配置法）

  1. 去模型厂商官网创建 API Key
  2. 在 OpenClaw 配置中写入 key
  3. 设置 primary 为 provider/model

配置示例：

# primary: "moonshot/"
# primary: "openai/"
# primary: "anthropic/"

CHANNELS

聊天软件配置

Telegram

  1. 在 Telegram 创建 Bot，拿到 token
  2. 在 OpenClaw 渠道配置中填写 token
  3. 绑定到你要使用的 workspace
查看 OpenClaw 配置文档

WhatsApp

  1. 开通 WhatsApp Business 或官方 API
  2. 在 OpenClaw 里启用 WhatsApp 渠道配置
  3. 完成回调地址与 token 配置
查看 OpenClaw 配置文档
