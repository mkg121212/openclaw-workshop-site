INSTALL GUIDE

OpenClaw 安装指南

本站只保留安装与配置步骤：环境准备 → OpenClaw → 模型 → TG/WA。

开始安装 直达 OpenClaw

SETUP

先装环境，再跑命令

macOS 环境

  • Homebrew
  • Node.js（建议 LTS，含 npm）
  • Git

安装命令

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew install node git

测试命令

node -v
npm -v
git --version

Windows 环境

  • 手动安装 Node.js LTS（官方安装包）
  • 手动安装 Git for Windows
  • 建议使用 PowerShell 或 Windows Terminal
  • 推荐可用版本：Node v22.x / npm v10.x / Git 2.50.x 左右
Node.js LTS 下载 Git for Windows 下载

OPENCLAW

安装 OpenClaw

环境准备好之后再安装 OpenClaw CLI。

安装命令

npm install -g openclaw

验证命令

openclaw --help

官方安装文档

遇到版本或平台差异时，以官方说明为准。

打开安装文档

OLLAMA

零成本跑通：Ollama 本地模型

点击安装 Ollama

下载与启动

ollama pull qwen2.5:7b
ollama serve

建议：首次用 7B 模型，速度快、资源占用小。

OpenClaw 模型配置

# OpenClaw 模型配置
# primary: "ollama/qwen2.5:7b"
Ollama 模型库

KIMI 2.5

付费模型：Kimi 2.5

适合已跑通流程、需要稳定效果的场景。

配置步骤

  1. 注册 Moonshot 账号
  2. 充值并获取 API Key
  3. 在 OpenClaw 配置中填 key

点击卡片可打开 Moonshot 控制台。

模型配置示例

# primary: "moonshot/"

CHANNEL SETUP

配置聊天软件入口（TG / WhatsApp）

Telegram

  1. 在 Telegram 创建 Bot，拿到 token
  2. 在 OpenClaw 渠道配置中填写 token
  3. 绑定到你要使用的 workspace
查看 OpenClaw 配置文档

WhatsApp

  1. 开通 WhatsApp Business 或官方 API
  2. 在 OpenClaw 里启用 WhatsApp 渠道配置
  3. 完成回调地址与 token 配置
查看 OpenClaw 配置文档
